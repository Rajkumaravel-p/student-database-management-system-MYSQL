# Student Database Management System

## 📌 Project Overview

The **Student Database Management System** is a MySQL-based database project designed to manage student information, departments, courses, and academic marks.

The project demonstrates how relational database concepts and SQL queries can be used to store, organize, retrieve, and analyze student academic data.

## 🛠️ Technologies Used

* MySQL
* SQL
* MySQL Workbench

## 🗂️ Database Tables

The database contains the following tables:

1. **Departments** – Stores department details.
2. **Students** – Stores student information and department details.
3. **Courses** – Stores course information and associated departments.
4. **Marks** – Stores students' marks for different courses.

## 🔗 Table Relationships

* Departments → Students
* Departments → Courses
* Students → Marks
* Courses → Marks

Primary Keys and Foreign Keys are used to establish relationships and maintain data integrity.
